# ICT Learning Hub

An interactive, attractive study companion for ICT students (Class 11–12 and beyond). Built with pure HTML, CSS and JavaScript — no backend, no build step. Ready for GitHub Pages.

## ✨ Features
- 8 ICT topics with lessons (Hardware, Software, Networks, Cybersecurity, Web, Databases, Programming, AI)
- Interactive quizzes with instant feedback and review
- 20 flashcards with flip animation + shuffle
- 25+ term glossary with search
- Progress tracking (localStorage)
- Dark / Light theme
- Fully responsive
- Offline-ready

## 🚀 Run locally
Just open `index.html` in any browser. No install needed.

## 🌐 Deploy on GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Source: **Deploy from a branch** → `main` / `/ (root)`.
4. Visit your site at `https://<username>.github.io/<repo>/`.

## 📁 Structure
```

```
